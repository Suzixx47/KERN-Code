#K.E.R.N. (AI Terminal OS)

**K.E.R.N.** — это экспериментальная терминальная среда на Python, превращающая нейросети (GigaChat и Gemini) в полноценного автономного ИИ-агента с доступом к файловой системе, сети и изолированной песочнице выполнения кода.

Проект создан энтузиастом (12 лет) для работы прямо с мобильного устройства (Android / Pydroid 3) в условиях ограниченных ресурсов.

## Ключевые возможности

- **Автономный агент `/chain` (Self-Healing)**: Агент способен выполнять сложные задачи в цикле (до 3 итераций). Coder пишет код, Sandbox запускает его в изолированной среде. Если возникает ошибка (Traceback), стек ошибки отправляется обратно Coder'у. Reviewer проверяет логику, и цикл повторяется до полного успеха.
- **Action System (Интеграция с ОС)**: K.E.R.N. умеет выполнять системные команды, создавать/удалять/читать файлы, скачивать файлы из сети, делать ZIP-архивы и парсить HTML-страницы (например, для работы с ГДЗ).
- **Два провайдера**: Поддержка GigaChat (Сбер) и Gemini (Google) с возможностью переключения на лету.
- **Долговременная память**: Сохранение важных фактов и контекста в memory.json.
- **Context Poisoning (Research)**: Механизм внедрения фейковой истории диалога (Fake History Attack), позволяющий исследовать устойчивость фильтров нейросетей к модификации контекста.

## Установка и запуск

1. Клонируйте репозиторий: `git clone https://github.com/Suzixx47/KERN-Code.git`
2. Перейдите в папку: `cd KERN-Code`
3. Установите зависимости: `pip install requests beautifulsoup4 urllib3`
4. Настройте API-ключи в config.py (GEMINI_API_KEY, GIGACHAT_AUTH_KEY) и выберите провайдера (PROVIDER).
5. Запустите интерфейс: `python ai_chat.py`
